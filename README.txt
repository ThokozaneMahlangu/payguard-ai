PAYGUARD PUBLIC WEBSITE — PREVIEW PACKAGE

1. Extract the ZIP.
2. Open PayGuard_Public_Site/index.html in your browser.
3. Click “Explore interactive demo” to open the fictional-data app.

PUBLISHING
Upload the CONTENTS of PayGuard_Public_Site (index.html, site.css,
site.js and demo/ folder) to a static web hosting provider.
The homepage and demo use relative links, so they can run from a subfolder.

IMPORTANT
- This is a public-facing PREVIEW, not a production payment service.
- The demo stores fictional data in local browser storage. It does not
  create online accounts or send reminders.
- The feedback box COPIES text only; it does not submit to a server.
  To collect feedback publicly, set up a suitable form service later.
- Do not add real customer details to the demo or upload your private
  PayGuard backups.
- No live AI API, subscription payments, or backend are included.
